# sparql-ft

This repository contains work-in-progress for finetuning small Qwen models to generate SPARQL queries against Yago.  The end goal is to use it to ground information retrieval, similar to GraphRAG.

The base of the code was mainly written using GLM-5.3 Flash through ZeroClaw, with tweaks and additions by me.  The code is released as public domain where applicable, or the WTFPL where public domain doesn't apply.
